Assumptions

These describe the server’s paper model. This file does not price a fill by itself.

  • Impact is order notional divided by pool liquidity. Buys pay above the mid. Sells receive below it.
  • If impact, fees, freshness, or the guardian fail, the server rejects the order. It does not invent a fill.
  • Shadow mode records a simulation and does not move cash.
  • Fill guarantee: false. Live trading is locked.
